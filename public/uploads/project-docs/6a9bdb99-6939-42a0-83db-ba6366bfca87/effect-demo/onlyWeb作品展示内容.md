# 异常报告自动入库与分析 Skill

一个用于处理钉钉 OA 异常报告导出 Excel 的 Skill，支持自动扫描导入、去重覆盖、字段理解、SQL 查询和趋势分析。

## 适合场景

- 异常报告数据分析
- 需要降低重复人工操作
- 需要把分散流程沉淀成可复用工具

## 业务痛点

- 异常报告散落在 Excel 文件中，难以持续统计
- 重复文件和新版本容易造成重复累计
- 按供应商、物料、部门和责任归属查询不方便
- 管理层需要快速看到异常趋势和风险点

## 解决流程

1. 定义异常报告文件识别和自动导入规则
2. 建立 SQLite 数据库和字段映射说明
3. 按文件哈希和业务主键处理去重更新
4. 提供扫描目录和单文件导入脚本
5. 通过 SQL 查询支持统计、筛选和趋势分析

## 使用效果

把一次性的异常报告 Excel 变成可持续查询的数据资产，方便统计问题类型、责任归属和风险趋势。

## 项目价值

- 减少人工汇总异常报告
- 避免重复导入导致统计失真
- 提升供应商和物料问题追踪效率
- 让异常分析可以被 AI 持续调用

## 我负责什么

- 设计自动入库工作流
- 实现 Excel 扫描、导入和去重逻辑
- 整理字段结构和查询模板
- 封装为可被 OpenClaw 调用的 Skill

- Python

- OpenClaw Skill
