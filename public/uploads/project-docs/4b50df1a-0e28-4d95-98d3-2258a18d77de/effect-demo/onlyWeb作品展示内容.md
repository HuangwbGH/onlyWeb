# 共享文件夹快速搜索助手

索引群晖 SMB 共享文件夹，提供文件名和目录名搜索、下载链接生成和 Agent Skill 调用能力，让共享资料检索像聊天一样简单。

## 适合场景

- 共享文件检索
- 需要降低重复人工操作
- 需要把分散流程沉淀成可复用工具

## 业务痛点

- 共享文件夹层级深，人工翻找耗时
- LinuxOS 和 macOS 访问共享目录差异大
- 同事只知道文件关键词时难以快速定位
- 找到文件后还需要生成可访问下载链接

## 解决流程

1. 梳理群晖共享目录访问方式
2. 建立本地 SQLite/FTS 文件索引
3. 实现多种文件名匹配模式和搜索 API
4. 生成带 token 的下载链接
5. 封装 Skill 让 AI 可以代替用户检索文件

## 使用效果

把共享文件夹搜索变成关键词检索和链接生成流程，减少人工在目录中反复翻找文件的时间。

## 项目价值

- 提升共享资料查找效率
- 适配 LinuxOS 和 macOS 使用场景
- 减少对管理员人工协助的依赖
- 让文件检索可以接入 AI 助手

## 我负责什么

- 设计共享目录索引和搜索接口
- 实现 SQLite/FTS 文件索引
- 封装搜索、链接生成和健康检查 API
- 编写 Skill 让 AI 可以调用文件搜索服务

## 技术实现

- Python 标准库
- SQLite FTS
- SMB / Synology
- HTTP API
- Docker Compose
- OpenClaw Skill
