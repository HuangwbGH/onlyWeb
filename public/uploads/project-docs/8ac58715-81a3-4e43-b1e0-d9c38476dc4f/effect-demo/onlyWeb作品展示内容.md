# 内部 Gemini 生图网站

为公司内部团队搭建可登录访问的 AI 生图网站，统一管理 Gemini API Key、部门权限、模型配置、代理、上传限制和生成记录。

## 适合场景

- 内部 AI 图片生成
- 需要降低重复人工操作
- 需要把分散流程沉淀成可复用工具

## 业务痛点

- 外部生图工具账号分散，难以统一管理
- 部门 API Key 和代理配置不集中
- 生成记录和素材难以沉淀
- 非技术同事需要简单的文生图和图生图入口

## 解决流程

1. 规划用户、部门、管理员和审核流程
2. 实现文生图、图生图和多图上传入口
3. 接入 Gemini 模型、API Key 和代理配置
4. 保存生成记录并支持预览、下载和删除
5. 通过 Docker 部署为内部可访问服务

## 使用效果

把公司内部 AI 生图需求集中到一个私有化网站，降低外部工具依赖并提升素材生成效率。

## 项目价值

- 统一管理部门 API Key
- 提升运营和内容团队出图效率
- 保留生成记录便于复用
- 为模板库和批量生成预留空间

- 实现用户登录、部门权限和管理员配置
- 接入 Gemini 图像生成能力
- 设计上传、生成、预览和下载流程
