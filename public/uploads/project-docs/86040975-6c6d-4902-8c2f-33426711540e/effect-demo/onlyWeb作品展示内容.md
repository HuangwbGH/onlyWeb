# Vibe Coding 规则知识库

用于约束 AI 编程协作方式的规则库，强调先规划、简单优先、最小改动、验证闭环和项目文档同步。

## 适合场景

- AI 编程协作规范
- 需要降低重复人工操作
- 需要把分散流程沉淀成可复用工具

## 业务痛点

- AI 写代码容易过度设计或改动过大
- 需求不清时容易直接实现导致返工
- 项目文档和代码变更容易不同步
- 不同工具之间缺少统一协作规则

## 解决流程

1. 整理 Think Before Coding 等核心原则
2. 定义简单优先和手术式修改规则
3. 明确目标驱动执行和验证方式
4. 把规则沉淀到 AGENTS.md 和全局规范文档
5. 在实际项目中持续使用和迭代

## 使用效果

形成一套可复用的 AI 编码协作规范，帮助减少无关改动、过度设计和文档遗漏。

## 项目价值

- 降低 AI 协作返工率
- 让代码修改更可控
- 强化测试和验证意识
- 统一不同项目的协作标准
