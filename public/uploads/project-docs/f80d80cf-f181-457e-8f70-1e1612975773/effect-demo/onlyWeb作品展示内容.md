# 采购订单规格自动核对助手

自动核对采购订单 Excel 与 PDF 图档规格，输出清晰的 Excel 报告。

## 适合场景

- 采购订单中有纸箱规格字段
- 同时存在对应的 PDF 图档
- 需要判断 Excel 规格与 PDF 图档规格是否一致
- 需要输出可复核、可归档的结果报告

## 业务痛点

- 人工逐个打开 PDF 核对规格耗时
- Excel 和图档分散，容易漏看或错配
- 异常项需要清楚标记，方便复核
- 多批次任务需要保留输入和输出记录

## 解决流程

1. 接收采购 Excel 与多个 PDF 图档。
2. 自动整理输入文件并建立任务目录。
3. 提取 Excel 行数据和 PDF 中的规格信息。
4. 自动比对文本规格与图示尺寸。
5. 生成带核对结果的 Excel 报告并归档。

## 使用效果

从采购 Excel 和 PDF 图档输入，到生成带结果标记的 Excel 报告，减少人工逐项对照。

## 项目价值

- 减少人工核对纸箱规格的重复工作
- 降低订单规格与图档不一致的漏检风险
- 让异常项集中进入报告，便于人工复核
- 保留任务输入、输出和中间结果，方便追溯

## 我负责什么

- 梳理采购订单与 PDF 图档核对流程
- 设计从输入到报告输出的自动化链路
- 实现 Excel 数据提取和 PDF 文件匹配
- 实现文本比对、图示尺寸识别和结果校验
- 设计输出报告和任务归档机制

## 技术实现

- Python 自动化
- Excel 数据读取
- PDF 文本解析
- OCR / 视觉辅助识别
- 结果校验
- Excel 报告生成
