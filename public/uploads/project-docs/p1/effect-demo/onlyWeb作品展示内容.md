# onlyWeb 个人求职与作品展示系统

用于维护个人资料、作品、经历、技能和不同岗位的定制投递页面，并支持作品文档、知识库、Docker 部署和文件夹化数据持久化。

## 适合场景

- 求职作品与定制简历展示
- 需要降低重复人工操作
- 需要把分散流程沉淀成可复用工具

## 业务痛点

- 单份简历难以匹配不同公司和岗位
- 作品、文档和联系方式分散
- HR 需要快速看到与岗位相关的信息
- 个人项目需要长期维护和统一入口

## 解决流程

1. 规划个人网站、作品集和定制页结构
2. 实现后台维护个人资料、作品、经历和技能
3. 实现 HR 专属分享页和作品在线预览
4. 接入 Markdown、Word、PDF 文档查看能力
5. 通过 Docker 和文件夹持久化简化部署迁移

## 使用效果

形成一个可长期维护的个人职业展示中枢，可以针对不同岗位生成更聚焦的展示页面。

## 项目价值

- 提升求职投递的针对性
- 统一沉淀个人作品和文档
- 让 HR 快速理解项目价值
- 降低个人网站部署和迁移成本
