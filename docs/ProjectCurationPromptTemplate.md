## 1. 使用场景

当需要把一个 GitHub 仓库整理成 onlyWeb 作品详情页内容时，使用本文档中的提示词。

目标不是让 AI 维护 onlyWeb 系统代码，而是让 AI 阅读某个作品仓库，并输出适合复制到 onlyWeb 作品页的展示内容。

目标读者包括：

- HR
- 人资总监
- 总经理
- 业务负责人
- 非技术管理者

因此输出内容应重点说明业务问题、使用场景、项目价值和个人贡献，技术实现只作为补充。

## 2. 使用方式

1. 把 [完整提示词](#3-完整提示词) 复制给 AI。
2. 把 `【填写 GitHub 仓库地址】` 替换成真实仓库地址。
3. 等 AI 输出 onlyWeb 字段格式。
4. 登录 onlyWeb 后，在作品详情页点击“编辑页面”，把内容复制到对应区域。
5. 如有项目文档或效果演示文档，在作品详情页“资料入口”编辑模式中直接上传。

## 3. 完整提示词


## 5. 输出检查清单

使用 AI 输出内容前，先检查：

- 是否面向非技术读者，而不是只面向程序员。
- 是否说明了真实业务问题。
- 是否避免编造无法验证的数据。
- 是否包含 onlyWeb 字段格式。
- “为什么要做”“怎么解决”“项目价值”是否足够短，适合页面展示。
- “我负责什么”是否是行动描述，而不是空泛评价。
- 技术实现标签是否简短，不要堆太多框架细节。
