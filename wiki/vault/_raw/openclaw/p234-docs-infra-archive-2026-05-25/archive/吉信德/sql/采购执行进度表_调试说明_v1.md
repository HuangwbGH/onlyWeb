# 采购执行进度表 v1 调试说明

## 当前版本定位
- 面向数据库：`UFDATA_101_2018`
- 版本性质：第一版可执行 SQL（过渡版）
- 目标：先验证采购执行主链路是否成立，再逐步补强未领量、目标到位日期、需求量来源

## 当前已实现
1. 以请购层为主入口
2. 采购层先明细后汇总
3. 兼容销售订单型 / 独立请购型
4. 产出缺口、卡点、逾期、影响判断、风险等级

## 当前占位项
### 1. 未领量
当前已经从“纯占位”升级为**基础版未领量**：
- 应领量：来自 `mom_orderdetail.Qty`
- 已领量：来自 `RdRecord11 + rdrecords11` 的生产订单领料出库
- 当前公式：`未领量 = 应领量 - 已领量`

当前仍未并入的部分：
- 补料量

后续若确认 `mom_replenishapplydtl` 或其他补料表存在稳定数据，再升级为：
- 未领量 = 应领量 + 补料量 - 已领量

### 2. 需求量
当前先取请购数量 `app_qty` 作为 `demand_qty`。
后续可升级为：
- 销售订单型：BOM 理论需求量优先
- 独立请购型：业务确认需求量优先

### 3. 目标到位日期
当前：
- 销售订单型：先取请购需求日期
- 独立请购型：先取最晚采购计划到货日期，若无则回退请购需求日期

## 首批重点核对口径
1. 请购未下达量 = 请购数量 - 采购下达数量
2. 采购在途量 = 采购数量 - 累计入库数量
3. 已到货未入库量 = 累计到货数量 - 累计入库数量
4. 剩余可用量 = 现库存 - 未领量 + 采购在途量（当前未领量暂为 0）
5. 当前卡点规则是否符合业务判断
