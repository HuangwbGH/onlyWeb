## 一、文档主题

该手册用于指导 **U8+ 产品加密锁注册**，核心目标是让用户完成：
- 加密锁获取
- IE 环境配置
- 安全插件安装
- 加密驱动安装
- 产品授权注册
- 加密服务重启
- 注册结果验证

---

## 二、标准操作流程

### 1. 获取产品加密锁
- 订单系统审批通过后
- 由生产管理部将 **加密锁 + 产品安装盘** 一并发送给用户

### 2. 运行 IE 配置工具
- 使用 **32 位 IE 浏览器** 打开注册网站：
  - `http://register.yonyou.com/`
- 点击左侧分类：**加密锁产品注册**
- 下载并运行 IE 配置工具
- 工具会自动获取 IP 地址
- 点击【下一步】→【开始配置】
- 配置过程中会自动关闭所有已打开的 IE 窗口
- 配置成功后会自动打开注册网站

### 3. 安装安全插件
- 正常情况下，运行 IE 配置工具后会自动后台安装
- 如未自动安装，需要手动安装：
  - 打开注册网站 `http://register.yonyou.com/`
  - 点击右侧【安全插件】图标
  - 点击【运行】
  - 安装过程中持续点击【下一步】
- **关键点**：IE 弹出的加载项提示必须全部选择 **允许运行**

### 4. 安装加密驱动
- 正常情况下 IE 配置工具会自动后台安装
- 如未自动安装：
  - 在左树点击【添加/删除驱动】
  - 点击【运行】
  - 进入驱动安装界面后按【下一步】安装
- 驱动安装成功后：
  - **需要重新插入加密锁**

### 5. 加密锁注册
- 在注册网站中点击左侧：**加密锁产品注册**
- 如果再次弹出 IE 配置工具提示，选择【取消】
- 进入注册主界面后，点击左树：**用户信息注册产品授权**
- 在右侧完善相关信息
- 点击【提交注册】

### 6. 获取注册结果
- 注册成功后，系统会自动生成：
  - **服务识别码**
  - **密码**
- 这两项需要妥善保管

### 7. 重启加密服务
- 登录【U8 应用服务管理】
- 选择【加密服务】
- 右键【属性】
- 在【常规】页签依次点击：
  - 【停止】
  - 【启动】
- 完成加密服务重启

### 8. 查看注册情况
- 登录【U8 应用服务管理】
- 右键【加密服务】→【属性】→【配置】
- 查看【产品登录情况】
- 如果：
  - 加密点
  - 并发点
  - 订单信息
  与实际订单一致
- 则说明注册正常

## 三、关键注意事项

### 1. 支持重复注册
- 如出现以下情况，可重新注册：
  - 重做系统
  - 更换加密服务器

### 2. 操作系统权限要求
- 必须使用 **administrator** 登录操作系统执行注册

### 3. 网络要求
- 执行注册的机器必须 **直连公网**
- **不允许使用 VPN 或任何代理方式联网**

### 4. 浏览器要求
- 只支持 **32 位 IE 浏览器**

## 四、实操要点总结

如果以后需要给别人讲解，可以直接按下面的最短流程说明：

1. 插入加密锁
2. 用 32 位 IE 打开 `http://register.yonyou.com/`
3. 先运行 IE 配置工具
4. 检查安全插件和加密驱动是否安装成功
5. 进入【用户信息注册产品授权】提交注册
6. 保存系统返回的 **服务识别码和密码**
7. 重启 U8 加密服务
8. 在【产品登录情况】里确认注册结果

## 五、后续可复用的检查清单

### 注册失败优先排查
- 是否使用了 **32 位 IE**
- 是否用了 **administrator** 账户
- 是否 **直连公网**
- 是否误用了 **VPN / 代理**
- 安全插件是否已安装并允许运行
- 加密驱动是否安装完成
- 驱动安装后是否重新插拔加密锁
- 提交注册后是否重启了加密服务
