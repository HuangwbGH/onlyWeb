### 1）Docker Hub 拉取加速
在 Linux 服务器上可先试：

```json
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://dockerproxy.com"
  ]
}
```

Docker 官方说明可以通过 `daemon.json` 里的 `registry-mirrors` 配置镜像加速。([docs.docker.com](https://docs.docker.com/docker-hub/mirror/?utm_source=openai))

常见配置文件位置：
- **Linux**：`/etc/docker/daemon.json`
- **Docker Desktop**：在 Docker Desktop 设置里改 daemon / engine 配置更合适；官方也说明有些 daemon 代理类配置在 Desktop 上要走设置页。([docs.docker.com](https://docs.docker.com/engine/daemon/?utm_source=openai))

配置后一般执行：

```bash
sudo systemctl daemon-reload
sudo systemctl restart docker
docker info
```

然后看输出里是否出现 `Registry Mirrors`。

---

### 2）如果你要“稳定可控”
更推荐你自己搭一个 **registry pull-through cache**，Docker 官方支持把本地 Registry 配成 Docker Hub 的缓存镜像。这样内网机器统一走你自己的镜像源，更稳。([docs.docker.com](https://docs.docker.com/docker-hub/mirror/?utm_source=openai))
